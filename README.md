# Fitness Mobile Application

A cross-platform fitness application built with React Native and Expo.

## Features

- Login and registration flows
- Home dashboard with workout shortcuts and statistics
- Workout catalogue with detailed exercises
- Nutrition plans with calories and macronutrients
- User profile and logout flow
- Bottom-tab and stack navigation

## Tech stack

- React Native
- Expo
- React Navigation
- Context API
- JavaScript

## Getting started

```bash
npm install
npm start
```

Use Expo Go or an Android/iOS emulator to run the application.
